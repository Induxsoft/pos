# Pos (Punto de Venta)
El paquete Pos (Punto de Venta) de V12 es el módulo que permite la gestión integral de operaciones de venta en mostrador, incluyendo la administración de cajas de efectivo, cajeros, tarjetas bancarias y terminales de procesamiento de tarjeta presente. Su propósito es centralizar y controlar las transacciones en puntos de venta físicos, asegurando trazabilidad, seguridad y eficiencia en la atención al cliente.
